02 — Engineering
Budget

The hard part was never the modelling.

Multiple products on one page is a memory and draw-call problem, not a geometry problem. One context, scissored viewports, lazy construction and explicit disposal are what keep it from falling over on a mid-range phone.

Reference rig

Meridian Mechanical is a fictional company built to demonstrate a multi-model architecture. Every unit here is procedural; a real deployment swaps them for the manufacturer's own geometry through the same loader.
